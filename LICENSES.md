# Licences and third-party notices

Ol1nPlay's own code: choose before publishing (MIT is the natural fit for
the Go and Dart code; the FFmpeg choice below may force your hand).

## FFmpeg (libavformat, libavcodec, libavutil)

FFmpeg is LGPL 2.1+ by default and GPL 2+ when built with `--enable-gpl`
(x264, x265, …) or `--enable-version3`/nonfree components.

- **LGPL shared build** (`*-lgpl-shared`): you may distribute Ol1nPlay
  under any licence, including closed source, as long as the FFmpeg DLLs
  stay separate (they do — the engine links dynamically), you ship the
  FFmpeg licence text and source offer, and you let users replace the
  DLLs. Nothing in Ol1nPlay needs a GPL component: it only demuxes and
  decodes.
- **GPL shared build** (`*-gpl-shared`, what the BtbN "gpl" zips are):
  the combined work is GPL; distribute Ol1nPlay under GPL 2+ (or 3).

The engine does not use libswresample, libswscale, libavfilter or
libavdevice; only the three libraries above are linked.

## ASIO (Steinberg)

ASIO is a trademark and software of Steinberg Media Technologies GmbH.
This repository contains **no part of the Steinberg ASIO SDK**.
`engine/asio/iasio.h` is an independent description of the public binary
interface (vtable layout, structs, constants) that every ASIO driver
exposes, written from the interface's documented behaviour — the same
approach JUCE takes since version 6.

Steinberg's position is that to develop and distribute an ASIO host you
must agree to the ASIO SDK Licence Agreement (free of charge) and comply
with its trademark rules (naming, logo). Do that before you publish a
build that mentions ASIO: https://www.steinberg.net/developers/

Never commit the SDK itself (`engine/third_party/asiosdk/` is git-ignored
for the case you keep a copy for reference).
